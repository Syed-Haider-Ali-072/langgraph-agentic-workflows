# 🤖 LangGraph Agentic Workflows

A practical collection of **five core agentic AI workflow patterns**, built with **LangGraph** and powered by **Groq**. Each pattern is a small, self-contained project with its own code, Streamlit UI and documentation, so you can learn how each one works and reuse it in your own applications.

| Pattern | What it does |
|---------|--------------|
| 🔗 **Sequential** | Runs stages one after another (editor → scriptwriter → translator) |
| ⚡ **Parallel** | Runs independent checks at the same time and merges the results |
| 🔁 **Iterative** | Writes, reviews and rewrites in a loop until the output is approved |
| 🔀 **Conditional (RAG)** | Routes each question to the right knowledge source or answers directly |
| 🧑‍⚖️ **Human-in-the-Loop** | Pauses for your approval or feedback before continuing |
